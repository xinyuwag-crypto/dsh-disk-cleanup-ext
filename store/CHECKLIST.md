# Store submission checklist

Everything you must do in the Chrome Web Store developer dashboard, in order. Items marked
**only you** need a human (account, payment, screenshots from the running extension).

## 0. Before you start

- [ ] Extension loads and the popup shows **已连接** (verified 2026-11-24)
- [ ] `dist/dsh-disk-cleanup-v1.0.1.zip` rebuilt after the last code change:
      `pwsh -File package.ps1`

## 1. Developer account (**only you**)

- [ ] Sign in at <https://chrome.google.com/webstore/devconsole>
- [ ] Pay the one-time **USD 5** registration fee
- [ ] Verify the publisher contact email (`xinyuwag@gmail.com`)

## 2. Privacy policy URL (prepared)

The policy page lives at `docs/privacy/index.html`. Publish it with GitHub Pages:

- [ ] Repo → **Settings** → **Pages**
- [ ] Source: **Deploy from a branch** → Branch `main` → folder **/docs** → **Save**
- [ ] Wait ~1 minute, then open
      `https://xinyuwag-crypto.github.io/dsh-disk-cleanup-ext/privacy/`
- [ ] Paste that URL into the dashboard’s **Privacy policy** field

## 3. Upload

- [ ] **New item** → upload `dist/dsh-disk-cleanup-v1.0.1.zip`
- [ ] Name: `DSH Disk Cleanup`
- [ ] Short description (132 chars):
      `Reads your DSH cleanup reports and clears browser cache, cookies and history in one click.`
- [ ] Detailed description: copy from `store/LISTING.md`
- [ ] Category: **Productivity**
- [ ] Language: Chinese (Simplified); add English as secondary

## 4. Permission justification (reviewer form)

| Permission | Paste this |
| --- | --- |
| `nativeMessaging` | Reads JSON reports produced locally by the companion desktop tool; required for the dashboard feature. |
| `browsingData` | The extension’s second feature is clearing cache, site data, and history at the user’s explicit request. |

- [ ] Single purpose statement:
      `Show local disk-cleanup reports and clear user-selected browser data.`

## 5. Graphics (**only you** for screenshots)

- [ ] Store icon: `icons/icon128.png` (already 128×128)
- [ ] Screenshots, 1280×800: **capture from the running extension**
      — open the popup, press `Win + Shift + S`, crop, then place on a 1280×800 canvas
      (do not fabricate UI; reviewers compare against the real popup)
- [ ] Small promo tile 440×280: `store/promo-440x280.png` (generated by `tools/make-store-assets.ps1`)

Suggested screenshot content:
1. Popup with **已连接** and the directory bars
2. Popup with the three clearing buttons and a success line

## 6. Submit

- [ ] Distribution: **Public**
- [ ] Regions: all
- [ ] Pricing: free
- [ ] Submit for review (usually 1–3 business days)

## 7. After approval (**important**)

The Web Store assigns a **new extension id**. Until the host knows it, the store build shows
“未连接”.

- [ ] Copy the new id from the store listing URL or the item page
- [ ] Run:
      ```powershell
      pwsh -File native-host\build-host.ps1 -ExtensionId <new-id>
      ```
- [ ] `pwsh -File native-host\verify-connection.ps1 -ExtensionId <new-id>` → expect all PASS
- [ ] Uninstall the unpacked dev copy so both do not compete
