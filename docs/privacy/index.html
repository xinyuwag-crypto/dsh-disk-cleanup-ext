DSH Disk Cleanup — Privacy Policy

Last updated: 2026-11-24 · Applies to the Chrome extension “DSH Disk Cleanup”

DSH Disk Cleanup（以下简称“本扩展”）只有一个用途：显示你自己电脑上由 DSH 清理工具生成的存储报告， 以及清理浏览器自己保存的数据。

1. 本扩展读取什么

  • 位于 %USERPROFILE%\.dsh\disk-cleanup\reports\ 的清理报告： structure.json、latest.json、structure.md。
  • 这些文件通过你自己安装并运行的本地宿主程序（native messaging）读取，不会离开你的电脑。
  • 报告内容只显示在扩展弹窗中，不上传、不写入云端、不做任何统计。

2. 本扩展会修改什么

  • 仅在你明确选择并二次确认后，清理浏览器数据：缓存、站点数据（Cookie、localStorage、IndexedDB、文件系统）、 浏览历史与下载记录。
  • 使用 Chrome 官方 browsingData API 完成，不涉及磁盘文件。

3. 本扩展不会做什么

  • 不读取、不删除、不上传磁盘上的任何文件。磁盘清理由独立的桌面工具完成，由你本人执行。
  • 没有分析、遥测、广告，也不加载远程代码。
  • 不访问网页内容，不读取标签页，不追踪浏览行为。

4. 权限说明

权限用途
nativeMessaging通过本机宿主读取清理报告。
browsingData执行你选择的浏览器数据清理。
storage仅保存弹窗自身状态，不存储个人数据。

5. 数据删除

卸载扩展后，删除 %USERPROFILE%\.dsh\disk-cleanup\ 即可同时移除报告与隔离区。 已清除的浏览器数据无法由本扩展恢复。

6. 联系方式

隐私相关问题请在扩展仓库提交 issue： dsh-disk-cleanup-ext/issues。

English summary: this extension reads local cleanup reports through a native messaging host you install yourself, and clears browser data only when you ask. It uploads nothing, contains no analytics, and never touches files on disk.
